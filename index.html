Дизайн робота

Как зовут робота и на чём он собран (например, LEGO SPIKE Prime). Главная идея конструкции в одном предложении.

📷 Фото робота

Конструкция

  • Шасси: два ведущих колеса и шаровая опора, компактная база для точных поворотов…
  • Насадки: быстросъёмные, меняются за несколько секунд…
  • Датчики: гироскоп для поворотов, датчики цвета для линии…
  • Моторы: 2 больших для движения, 2 средних для насадок…

Как мы проектировали

  1. ИдеиРазобрали задания поля и придумали, какие механизмы нужны.
  2. ПрототипСобрали первую версию и проверили её на поле.
  3. ТестыЗаписывали результаты запусков и искали слабые места.
  4. УлучшенияЧто изменили по итогам тестов (например, «сделали базу ниже, чтобы робот не опрокидывался»).

Код робота

На чём программируем (например, Python в LEGO SPIKE App) и кто в команде отвечает за код.

🧩

Модульность

Повторяющиеся действия (ехать прямо, повернуть, поднять насадку) вынесены в отдельные функции — их легко переиспользовать и исправлять.

🧭

Точность

Повороты по гироскопу и движение по линии с П/ПИД-регулятором, чтобы робот ехал одинаково при любом заряде батареи.

⏱️

Скорость

Все миссии разбиты на N запусков, запуск выбирается одной кнопкой.

Пример кода

Замените этот пример фрагментом вашей программы.

# Пример: поворот по гироскопу (LEGO SPIKE Prime, Python)
from hub import motion_sensor, port
import motor_pair, runloop

motor_pair.pair(motor_pair.PAIR_1, port.A, port.B)

async def turn(angle, speed=200):
    motion_sensor.reset_yaw(0)
    # tilt_angles()[0] — рыскание (yaw) в десятых долях градуса
    while abs(motion_sensor.tilt_angles()[0]) < angle * 10:
        motor_pair.move_tank(motor_pair.PAIR_1, speed, -speed)
        await runloop.sleep_ms(5)
    motor_pair.stop(motor_pair.PAIR_1)
