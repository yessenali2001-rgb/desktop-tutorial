# Telegram-бот: помощник по робототехнике

Бесплатный Telegram-бот, который отвечает на вопросы по робототехнике из
встроенной базы ответов. Платные сервисы и ИИ не используются: сам Telegram Bot
API бесплатный, а бот может работать на вашем компьютере или на бесплатном
хостинге.

## Как работает

- `/start` — меню с темами:
  - ⚙️ Двигатели и приводы
  - 🔋 Электроника и питание
  - 📡 Датчики
  - 💻 Arduino и программирование
  - 🧠 Алгоритмы (езда по линии, ПИД, объезд препятствий)
  - 🏆 Наборы, соревнования, обучение
- Тема → список вопросов → ответ с примерами кода для Arduino.
- Можно просто написать вопрос текстом («как подключить сервопривод»): бот
  найдёт подходящие ответы по ключевым словам и предложит их кнопками.

Бот отвечает только на то, что есть в базе. Вопросы и ответы лежат в
`src/faq.ts` — их легко дополнять.

## Запуск

Нужен Node.js 20+.

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`,
   придумайте имя и username бота. BotFather пришлёт токен.
2. Установите и настройте:
   ```bash
   npm install
   cp .env.example .env    # в Windows: copy .env.example .env
   ```
   Впишите токен в `.env`: `BOT_TOKEN=123456789:AAH...`
3. Запустите:
   ```bash
   npm run dev
   ```
   Появится `Robotics bot started`. Откройте своего бота в Telegram и нажмите
   «Старт».

Бот получает сообщения сам (long polling), поэтому ни ngrok, ни HTTPS-сервер не
нужны. Бот работает, пока запущена программа.

Для круглосуточной работы запустите его на любом сервере или хостинге, где
можно держать постоянно работающий Node.js-процесс:
```bash
npm run build && npm start
```

## Как добавить вопрос

Откройте `src/faq.ts` и добавьте в нужную тему объект:

```ts
{
  id: "my-question",              // латиница, цифры, дефисы; уникальный
  question: "Текст вопроса?",
  keywords: ["ключ", "слово"],    // начала слов в нижнем регистре для поиска
  answer: "Текст ответа",         // b("жирный"), pre(`код`) для кода
},
```

После изменений запустите `npm test` — тесты проверят, что идентификаторы
уникальны, разметка ответов корректна и поиск находит нужные ответы.

## Структура

```
src/
  bot.ts        обработчики Telegram: меню, кнопки, поиск
  faq.ts        база вопросов и ответов
  search.ts     поиск ответа по ключевым словам
  config.ts     токен бота из .env
  faq.test.ts   тесты базы и поиска
```
