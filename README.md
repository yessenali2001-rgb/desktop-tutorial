# Семейный бюджет

Простой сайт для учёта доходов и расходов семьи. Работает без сервера: данные хранятся в браузере (localStorage).

## Возможности

- Доходы и расходы по категориям, с указанием члена семьи и комментарием
- Сводка за месяц: доходы, расходы, баланс; переключение между месяцами
- Диаграммы: расходы по категориям и кто сколько потратил
- Общий бюджет семьи на месяц: сколько потрачено, сколько осталось и сколько можно тратить в день до конца месяца
- Месячные лимиты по категориям (жёлтый — потрачено 80%+, красный — лимит превышен)
- Отдельный лист для каждого члена семьи: свои доходы, расходы, баланс и операции (вкладки сверху). Лист «Вся семья» показывает всё вместе
- Свои члены семьи и категории
- Экспорт/импорт данных в JSON (резервная копия или перенос на другое устройство)

## Запуск

Откройте `index.html` в браузере — данные сохранятся только в этом браузере.

Если страница опубликована как артефакт на claude.ai, она подключается к общей базе: все, с кем поделились страницей (с правами Contributor), видят и заполняют один бюджет. Прежние записи из браузера можно перенести в общий бюджет одной кнопкой. Для публикации включите GitHub Pages в настройках репозитория (Settings → Pages → ветка с этими файлами).

Валюта задаётся константой `CURRENCY` в начале `app.js`.
