# Спартакиада 2026 — сайт

Виды спорта: волейбол әкелер (папы), волейбол аналар (мамы), настольный теннис, шахматы.

Запуск (Node 18+, зависимости не нужны):

    ORGANIZER_PASSWORD='ваш-пароль' node server.js

Откройте http://localhost:3000

## Кто что может
- **Родители** — вход без пароля, только просмотр: участники (имя и класс), матчи, счёт, таблицы, блок «Сейчас идёт» (обновляется каждые 5 секунд). Контакты родителей им не показываются.
- **Организаторы** — вход по паролю. При первом запуске создаются аккаунты (пароли печатаются в консоль один раз, хранятся в `data/users.json` в виде хэша):
  - `organizer` — главный: расписание, объявление, все виды спорта;
  - `org_volleyball` (оба волейбола), `org_tennis`, `org_chess` — каждый управляет только своими видами спорта.

## Турниры
| Вид спорта | Форматы |
|---|---|
| Волейбол | Лига (каждый с каждым) · Чемпионат (на вылет) |
| Настольный теннис | Лига · Групповой (группы + матчи внутри) |
| Шахматы | Блиц (каждый с каждым) · Швейцарская система (туры) |

Организатор добавляет участников (имя, класс, родитель — можно вставить списком `Имя; Класс; Родитель`), выбирает формат, нажимает «Составить матчи», затем вводит счёт и ставит статус «Идёт сейчас» / «Завершён». Таблицы считаются автоматически. Изменения сохраняются сами.

Данные лежат в `data/` (не попадают в git). Чтобы сбросить пароли, удалите `data/users.json`.

## Фирменный стиль
Светлая тема, цвета «Білім-Инновация»: тёмно-синий `#111233` и золотисто-песочный `#CAB391`. Логотип — чёрно-белая эмблема с голубем (`assets/emblem.png`, она же иконка вкладки `assets/favicon.png`) и надпись «БІЛІМ-ИННОВАЦИЯ». Прежние логотипы из брендбука лежат в `assets/` (`logo-main.png`, `logo-white.png`). Шрифт — Montserrat (подключается с Google Fonts, без интернета заменяется системным).

## Арены волейбола
Волейбол әкелер проходит на двух аренах («Арена 1», «Арена 2»), волейбол аналар — на одной («Арена 3»); названия правит организатор. При автоматическом составлении матчи тура раскладываются по аренам по кругу, арену можно поменять у каждого матча. Родители видят на карточках арен, что идёт сейчас и что дальше.

## Публикация в интернете
Нужен хостинг, где работает Node.js (GitHub Pages не подойдёт), с HTTPS и **постоянным диском** — иначе при перезапуске пропадут участники и результаты.

Переменные окружения:
| Переменная | Назначение |
|---|---|
| `ORGANIZER_PASSWORD`, `ORG_VOLLEYBALL_PASSWORD`, `ORG_TENNIS_PASSWORD`, `ORG_CHESS_PASSWORD` | пароли организаторов (не короче 8 символов); задаются на хостинге, в git не хранятся |
| `DATA_DIR` | папка постоянного диска (например `/var/data`) |
| `TRUST_PROXY=1` | если сайт стоит за прокси хостинга (почти всегда) |
| `PORT` | порт (большинство хостингов задают сами) |

**Render.com:** New → Blueprint → выберите этот репозиторий и ветку; `render.yaml` создаст сервис с диском. Платформа спросит четыре пароля. **Docker/Fly.io/Railway:** собирается из `Dockerfile`, данные в `/data` (подключите том).
Проверка работоспособности: `/healthz`.
