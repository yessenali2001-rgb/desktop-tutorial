# Шығу рұқсаты: оқушыны сабақтан босату жүйесі

Оқушы сабақ кезінде ауырып қалса немесе үйге кетуі керек болса, енді завучқа қоңырау шалудың қажеті жоқ.

1. **Сынып жетекшісі** сайтқа кіріп, оқушының аты-жөнін, сыныбын, себебін, қайда баратынын және кім алып кететінін жазады.
2. **Завуч** өтінімді бірден көреді (5 секунд сайын жаңарады, дыбыс шығады) және **✓ Рұқсат беру** немесе **✕ Бас тарту** басады.
3. **Күзетші** тек рұқсат берілген оқушыларды көреді. Оқушы шыққанда **«Шығып кетті»** басады, сол кезде уақыты жазылып қалады.

Сынып жетекшісі өтінімнің күйін (күтуде / рұқсат / шықты) өз бетінен көріп отырады. Барлық өтінімдер күн бойынша сақталады, завуч кез келген күннің тарихын аша алады.

## Іске қосу

Тек [Node.js](https://nodejs.org) (18 не одан жаңа) керек, басқа ештеңе орнатудың қажеті жоқ.

```bash
node server.js
```

Сайт `http://localhost:3000` мекенжайында ашылады.

Алғаш іске қосқанда бір ғана қолданушы жасалады:

- логин: `zavuch`
- құпия сөз: `zavuch123` (немесе `ZAVUCH_PASSWORD` айнымалысында берілген)

**Кіргеннен кейін құпия сөзді бірден ауыстырыңыз** (жоғарғы оң жақтағы «Құпия сөз» батырмасы). Содан кейін «Қолданушылар» бетінде әр сынып жетекшісіне және күзетшіге логин мен құпия сөз беріңіз.

### Баптаулар

| Айнымалы | Мәні | Әдепкі |
|---|---|---|
| `PORT` | Сервер порты | `3000` |
| `ZAVUCH_PASSWORD` | Бірінші завуч құпия сөзі (тек алғаш іске қосқанда) | `zavuch123` |
| `DATA_DIR` | Деректер сақталатын бума | `./data` |
| `TZ_SCHOOL` | Уақыт белдеуі | `Asia/Almaty` |

Барлық деректер `data/db.json` файлында сақталады. Осы файлдың көшірмесін жасап отырсаңыз жеткілікті.

## Интернетке шығару

Сайтты барлық мұғалімдер телефоннан аша алуы үшін оны серверге орналастыру керек. Екі жол бар:

- **Мектептің ішкі желісінде:** мектептегі кез келген компьютерде `node server.js` іске қосыңыз. Мұғалімдер сол компьютердің IP мекенжайы арқылы кіреді, мысалы `http://192.168.1.10:3000`. Компьютер сабақ кезінде қосулы тұруы керек.
- **Хостингте:** Render, Railway немесе кез келген VPS. Start command: `node server.js`. `data/` бумасына сақталатын диск (persistent disk) міндетті түрде қосылсын, әйтпесе қайта іске қосқанда деректер өшіп қалады. Сыртқа шығарғанда HTTPS қолданыңыз.
