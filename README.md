# Кабинет ученика

Сайт для класса из 25 учеников. База данных — **Google Таблица**, сервер — **Google Apps Script**.

Ученики и родители только смотрят. Сам ученик меняет список прочитанных книг и свои цели (IDP): добавляет цели и шаги, отмечает выполненное, удаляет. Наставника, сильные стороны и комментарий к IDP меняют учитель и воспитатель прямо на сайте. Остальные данные заполняют учитель и воспитатель: в Google Таблице, а посещаемость ещё и на сайте.

Ученик выбирает своё имя из списка, вводит PIN-код и видит:

- 📅 **Расписание** на неделю с кабинетами и учителями (сегодняшний день подсвечен) и 📆 **ближайшие события** (Алдағы күнтізбе);
- 🎯 **IDP план**: цели, шаги, сроки, прогресс и комментарий учителя;
- ✅ **Посещаемость этюда**: сколько раз был, отсутствовал, опоздал или отсутствовал по уважительной причине, с историей по датам;
- 📊 **Оценки (табель)**: оценки по четвертям, годовые, экзаменационные и итоговые за каждый учебный год, средний балл, поведение и пропущенные уроки;
- 📖 **Прочитанные книги**: список и количество; ученик сам добавляет прочитанные книги и может удалить ошибочную запись;
- 📁 **Портфолио**: личная информация (в том числе адрес), оценки, достижения, сертификаты, хобби, книги, языки, поездки, цели на будущее;
- 🏅 **Олимпиады**, 📝 **экзамены** (KET, BTS и др.) и 🧠 **результаты тестов** (ИСН, Гарднер, темперамент) с пояснениями;
- 📚 **Ресурсы** (например, ресурсы по английскому).

Родитель на вкладке **«Родитель»** выбирает своего ребёнка из списка и вводит **номер телефона мамы или папы**. Логин вводить не нужно. Номера в таблице записаны в формате `8 701 234 56 78`, но родитель может вводить номер в любом виде: `8 701 234 56 78`, `+7 701 234 56 78`, `87012345678`. Родитель видит то же, что и ребёнок (расписание, IDP, посещаемость), плюс блок «Последние отсутствия и опоздания на этюде».

Учитель и воспитатель входят на вкладке «Учитель»: выбирают из списка «Учитель» или «Воспитатель» и вводят PIN-код. Никому не нужно вводить логин. Учитель и воспитатель видят:

- **сводку** по всем ученикам (отсутствия и опоздания на этюдах, % посещаемости, прогресс IDP, олимпиада, день рождения);
- **отметить этюд**: выбирает дату, отмечает «Был», «Отсутствовал», «Опоздал» или «Уважительная причина» и сохраняет прямо в Google Таблицу;
- **журнал этюдов**: таблицу «ученик × этюд», где видно, кто был, а кто пропустил;
- **оценки класса**: средний балл каждого ученика, отличники, хорошисты, у кого есть «3», пропущенные уроки;
- **цели всех учеников**, **олимпиады**, **экзамены**, **тесты** по всему классу;
- 🎂 **дни рождения** в ближайшие 30 дней;
- страницу любого ученика с телефонами родителей (номер можно нажать, чтобы позвонить).

## Как это устроено

```
Сайт (GitHub Pages)  ──►  Apps Script (проверяет PIN)  ──►  Google Таблица
```

На странице входа виден только список имён класса. PIN-коды и телефоны хранятся только в таблице и никогда не отправляются ученикам и родителям. Ученик и его родитель получают с сервера **только данные этого ученика**. Телефоны родителей видит только учитель. После 5 неверных попыток вход блокируется на 10 минут.

## Настройка (один раз, ~10 минут)

### 1. Создать таблицу и скрипт

1. Создайте новую Google Таблицу: [sheets.new](https://sheets.new).
2. Откройте меню **Расширения → Apps Script**.
3. Замените содержимое файла `Code.gs` кодом из [`apps-script/Code.gs`](apps-script/Code.gs).
4. Нажмите **＋ → Скрипт**, назовите файл `Seed` и вставьте код из [`apps-script/Seed.gs`](apps-script/Seed.gs). Это тестовые данные, этот шаг можно пропустить.
5. Сохраните (💾), выберите в списке функцию **`setup`** и нажмите **Выполнить**. Google попросит разрешение, разрешите.

В таблице появятся листы: **Настройки**, **Ученики**, **Расписание**, **IDP**, **Посещаемость**.

> **Загрузить готовый файл вместо тестовых данных.** Если у вас есть подготовленный `.xlsx` со всеми листами, загрузите его на Google Диск, откройте как Google Таблицу (**Файл → Сохранить как Google Таблицу**) и уже в ней откройте **Расширения → Apps Script** и вставьте только `Code.gs`. `Seed.gs` и `setup` в этом случае не нужны.

### 2. Опубликовать как веб-приложение

1. В Apps Script: **Начать развертывание → Новое развертывание**.
2. Тип (⚙️): **Веб-приложение**.
3. Выполнять как: **Я**. У кого есть доступ: **Все**.
4. Нажмите **Начать развертывание** и скопируйте **URL веб-приложения**. Он заканчивается на `/exec`.

### 3. Подключить сайт

Вставьте URL в файл [`config.js`](config.js):

```js
const CONFIG = {
  API_URL: "https://script.google.com/macros/s/.../exec",
};
```

Пока `API_URL` пустой, сайт работает в **демо-режиме** на тестовых данных из `data.js`.

### 4. Опубликовать сайт

В репозитории на GitHub: **Settings → Pages → Branch: main → Save**. Через минуту сайт будет доступен по ссылке.

> 🔒 Не храните настоящие данные учеников в этом репозитории: они должны быть только в Google Таблице. `data.js` и `Seed.gs` содержат выдуманные данные для демо.

> ⚠️ Если вы изменили `Code.gs`, нужно выпустить новую версию: **Начать развертывание → Управление развертываниями → ✏️ → Версия: Новая → Развернуть**. Иначе будет работать старый код.

## Как вести данные в таблице

| Лист | Что там |
|---|---|
| **Настройки** | Название класса, логины и PIN-коды учителя и воспитателя, список этюдов |
| **Ученики** | Фото (колонка «Фото» заполняется сама, когда учитель или воспитатель загружает фото на сайте: оно уменьшается до 256×256 и хранится прямо в ячейке, без публичных ссылок). ID (внутренний код ученика, например `S01`; на сайте он не показывается, ученик выбирает своё имя из списка), ФИО, PIN, наставник, сильные стороны, комментарий учителя, телефон мамы, телефон папы. Если телефона одного из родителей нет, оставьте ячейку пустой |
| **Расписание** | Одна строка — один урок: день, № урока, время, предмет, кабинет, учитель. Сдвоенный урок — две строки. Урок по группам — одна строка, в кабинете и учителе пишите «гр.1: … · гр.2: …» |
| **Календарь** | Ближайшие события: дата начала, дата окончания (если событие длится несколько дней), название. Прошедшие события ученики не видят |
| **IDP** | Цели ученика. Простая цель — одна строка: ID, цель, срок (дата или текст, например «до конца 8 класса»), ☑ выполнено. Цель из нескольких шагов — строка на каждый шаг с одинаковой целью |
| **Портфолио** | Одна строка — один пункт: ID ученика, раздел, название, детали, дата/год. Разделы: Личное (в том числе «Адрес»), Оценки, Достижения, Сертификаты, Хобби, Прочитанные книги (название книги, автор, когда прочитал — показываются во вкладке «Книги»), Языки, Поездки, Цели на будущее (можно добавлять свои). Дата рождения (раздел «Личное») нужна для списка дней рождения |
| **Оценки** | Табель: одна строка — один предмет за один учебный год: ID ученика, «Класс, учебный год» (например `8А · 2025/2026`), предмет и оценки за 1–4 тоқсан, жылдық, емтихан, қорытынды. Строки «Тәртібі», «Сабақ саны», «Қатыспаған сабақ» — поведение, число уроков и пропущенные уроки |
| **Олимпиады**, **Экзамены**, **Тесты** | Строка на ученика: ID, ФИО и колонка на каждый показатель. Колонки можно добавлять и переименовывать, сайт покажет их как есть |
| **Ресурсы** | Раздел, ресурс и где показывать: пусто — во вкладке «Ресурсы», «Тесты» — как пояснение во вкладке «Тесты» |
| **Посещаемость** | Одна строка — один проведённый этюд: дата, этюд и ID отсутствовавших через запятую (`S03, S07`) в колонках «Отсутствовали», «Опоздали», «Уважительная причина». Все остальные считаются присутствовавшими |

Посещаемость удобнее отмечать на сайте, во вкладке **«Отметить этюд»**: строки в таблицу добавятся сами. Этюд один в день (лист «Настройки», строка «Этюды»: `Этюд`). Если когда-нибудь понадобится несколько, перечислите их через запятую, например `1 этюд, 2 этюд`, и на сайте появится выбор этюда.

Изменения в таблице сразу видны на сайте: достаточно обновить страницу.

Чтобы начать с чистого листа, удалите тестовые строки (кроме заголовков) из листов и впишите своих учеников.
