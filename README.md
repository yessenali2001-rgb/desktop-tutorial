# Кабинет ученика

Сайт для класса из 25 учеников. Каждый ученик входит под своим логином и видит:

- 📅 **Расписание** на неделю (сегодняшний день подсвечен);
- 🎯 **IDP план**: цели, шаги, сроки, прогресс и комментарий учителя;
- ✅ **Посещаемость**: сколько уроков был, сколько пропустил или опоздал, отдельно по каждому предмету и по датам.

Учитель входит под логином `teacher` и видит:

- **сводку** по всем ученикам (пропуски, опоздания, % посещаемости, прогресс IDP), с сортировкой «больше всего пропусков»;
- **журнал**: таблицу «ученик × урок», где видно, кто был, а кто пропустил;
- **IDP всех учеников**;
- страницу любого ученика (по клику на имя).

## Как открыть

Откройте `index.html` в браузере. Сервер не нужен.

Чтобы сайт был доступен по ссылке, включите GitHub Pages: **Settings → Pages → Branch → Save**.

## Как обновлять данные

Все данные лежат в файле **`data.js`**:

| Что изменить | Где в `data.js` |
|---|---|
| Название класса | `className` |
| Логин/PIN учителя | `teacher` |
| Расписание | `schedule` |
| Ученики, их PIN-коды, IDP | `students` |
| Посещаемость | `attendance` — одна запись на каждый проведённый урок |

Пример записи в журнале посещаемости: указываются только отсутствующие, все остальные считаются присутствовавшими.

```js
{ "date": "2026-09-23", "subject": "Математика", "absent": ["S03"], "late": ["S10"], "excused": [] }
```

Отметить шаг IDP выполненным: `"done": true`.

> ⚠️ Сейчас в файле **тестовые** имена, PIN-коды и посещаемость. Замените их на реальные.
>
> ⚠️ Это статический сайт: PIN-коды лежат в `data.js`, и технически подкованный человек может их там найти. Для учебного кабинета этого обычно хватает. Для настоящей защиты данных нужен сервер с базой данных.
