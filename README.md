# Кабинет ученика

Сайт для класса из 25 учеников. База данных — **Google Таблица**, сервер — **Google Apps Script**.

Ученики и родители только смотрят. Заполняют данные учитель и воспитатель: в Google Таблице, а посещаемость ещё и на сайте.

Ученик выбирает своё имя из списка, вводит PIN-код и видит:

- 📅 **Расписание** на неделю (сегодняшний день подсвечен);
- 🎯 **IDP план**: цели, шаги, сроки, прогресс и комментарий учителя;
- ✅ **Посещаемость**: сколько уроков был, сколько пропустил или опоздал, по каждому предмету и по датам;
- 📁 **Портфолио**: личная информация, оценки, достижения, сертификаты, хобби, книги, языки, поездки, цели на будущее;
- 🏅 **Олимпиады**, 📝 **экзамены** (KET, BTS и др.) и 🧠 **результаты тестов** (ИСН, Гарднер, темперамент) с пояснениями;
- 📚 **Ресурсы** (например, ресурсы по английскому).

Родитель на вкладке **«Родитель»** выбирает своего ребёнка из списка и вводит **номер телефона мамы или папы**. Логин вводить не нужно. Номер можно вводить в любом виде: `+7 701 234 56 78`, `87012345678`, `7012345678`. Родитель видит то же, что и ребёнок (расписание, IDP, посещаемость), плюс блок «Последние пропуски и опоздания» и вкладку **«Мероприятия родителей»**: какие собрания и мероприятия посетил родитель.

Учитель (логин `teacher`) и воспитатель (логин `vospitatel`) входят на вкладке «Учитель» и видят:

- **сводку** по всем ученикам (пропуски, опоздания, % посещаемости, прогресс IDP);
- **отметить урок**: выбирает дату и предмет, отмечает отсутствующих и сохраняет прямо в Google Таблицу;
- **журнал**: таблицу «ученик × урок», где видно, кто был, а кто пропустил;
- **цели всех учеников**, **олимпиады**, **экзамены**, **тесты** и **участие родителей в мероприятиях** (с телефонами) по всему классу;
- 🎂 **дни рождения** в ближайшие 30 дней;
- страницу любого ученика с телефонами родителей (номер можно нажать, чтобы позвонить).

## Как это устроено

```
Сайт (GitHub Pages)  ──►  Apps Script (проверяет PIN)  ──►  Google Таблица
```

На странице входа виден только список имён класса. PIN-коды и телефоны хранятся только в таблице и никогда не отправляются ученикам и родителям. Ученик и его родитель получают с сервера **только данные этого ученика**. Телефоны родителей видит только учитель. После 5 неверных попыток вход блокируется на 10 минут.

## Настройка (один раз, ~10 минут)

### 1. Создать таблицу и скрипт

1. Создайте новую Google Таблицу: [sheets.new](https://sheets.new).
2. Откройте меню **Расширения → Apps Script**.
3. Замените содержимое файла `Code.gs` кодом из [`apps-script/Code.gs`](apps-script/Code.gs).
4. Нажмите **＋ → Скрипт**, назовите файл `Seed` и вставьте код из [`apps-script/Seed.gs`](apps-script/Seed.gs). Это тестовые данные, этот шаг можно пропустить.
5. Сохраните (💾), выберите в списке функцию **`setup`** и нажмите **Выполнить**. Google попросит разрешение, разрешите.

В таблице появятся листы: **Настройки**, **Ученики**, **Расписание**, **IDP**, **Посещаемость**.

> **Загрузить готовый файл вместо тестовых данных.** Если у вас есть подготовленный `.xlsx` со всеми листами, загрузите его на Google Диск, откройте как Google Таблицу (**Файл → Сохранить как Google Таблицу**) и уже в ней откройте **Расширения → Apps Script** и вставьте только `Code.gs`. `Seed.gs` и `setup` в этом случае не нужны.

### 2. Опубликовать как веб-приложение

1. В Apps Script: **Начать развертывание → Новое развертывание**.
2. Тип (⚙️): **Веб-приложение**.
3. Выполнять как: **Я**. У кого есть доступ: **Все**.
4. Нажмите **Начать развертывание** и скопируйте **URL веб-приложения**. Он заканчивается на `/exec`.

### 3. Подключить сайт

Вставьте URL в файл [`config.js`](config.js):

```js
const CONFIG = {
  API_URL: "https://script.google.com/macros/s/.../exec",
};
```

Пока `API_URL` пустой, сайт работает в **демо-режиме** на тестовых данных из `data.js`.

### 4. Опубликовать сайт

В репозитории на GitHub: **Settings → Pages → Branch: main → Save**. Через минуту сайт будет доступен по ссылке.

> 🔒 Не храните настоящие данные учеников в этом репозитории: они должны быть только в Google Таблице. `data.js` и `Seed.gs` содержат выдуманные данные для демо.

> ⚠️ Если вы изменили `Code.gs`, нужно выпустить новую версию: **Начать развертывание → Управление развертываниями → ✏️ → Версия: Новая → Развернуть**. Иначе будет работать старый код.

## Как вести данные в таблице

| Лист | Что там |
|---|---|
| **Настройки** | Название класса, логины и PIN-коды учителя и воспитателя |
| **Ученики** | ID (логин ученика, например `S01`), ФИО, PIN, наставник, сильные стороны, комментарий учителя, телефон мамы, телефон папы. Если телефона одного из родителей нет, оставьте ячейку пустой |
| **Расписание** | Одна строка — один урок: день, № урока, время, предмет, кабинет |
| **IDP** | Цели ученика. Простая цель — одна строка: ID, цель, срок (дата или текст, например «до конца 8 класса»), ☑ выполнено. Цель из нескольких шагов — строка на каждый шаг с одинаковой целью |
| **Портфолио** | Одна строка — один пункт: ID ученика, раздел, название, детали, дата/год. Разделы: Личное, Оценки, Достижения, Сертификаты, Хобби, Прочитанные книги, Языки, Поездки, Цели на будущее (можно добавлять свои). Дата рождения (раздел «Личное») нужна для списка дней рождения |
| **Олимпиады**, **Экзамены**, **Тесты** | Строка на ученика: ID, ФИО и колонка на каждый показатель. Колонки можно добавлять и переименовывать, сайт покажет их как есть |
| **Мероприятия родителей** | Строка на ученика, колонка на каждое мероприятие; ☑ (или 1) — родитель пришёл. Новое мероприятие — новая колонка |
| **Ресурсы** | Раздел, ресурс и где показывать: пусто — во вкладке «Ресурсы», «Тесты» — как пояснение во вкладке «Тесты» |
| **Посещаемость** | Одна строка — один проведённый урок: дата, предмет и ID отсутствовавших через запятую (`S03, S07`) в колонках «Пропуск», «Опоздал», «Уважительная причина». Все остальные считаются присутствовавшими |

Посещаемость удобнее отмечать на сайте, во вкладке **«Отметить урок»**: строки в таблицу добавятся сами.

Изменения в таблице сразу видны на сайте: достаточно обновить страницу.

Чтобы начать с чистого листа, удалите тестовые строки (кроме заголовков) из листов и впишите своих учеников.
